# Engineering roadmap

## v0.3 — foundation (this package)
Executable specifications, API skeleton, migrations, tests, Bororo manifest.

## v0.4 — ingestion
Idempotent import jobs, source manifests, validation reports, CoNLL-U and dictionary staging tables.

## v0.5 — editorial workflow
Review assignments, immutable audit events, publication snapshots and role-based permissions.

## v0.6 — corpus and lexicon
Interactive text reader, token annotations, lexical occurrence linking and search indexing.

## v0.7 — evidence and grammar
Claim/evidence graph, grammar authoring and stable citations.
